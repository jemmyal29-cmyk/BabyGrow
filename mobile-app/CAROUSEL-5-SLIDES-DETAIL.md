## 🎨 **LOGO FORMULA (ALWAYS CIRCULAR):**

```typescript
// Universal Circular Logo Formula
logoCircle: {
  width: SIZE,              // e.g., 140 or 120
  height: SIZE,             // Same as width
  borderRadius: SIZE / 2,   // ← KEY: Always half of width/height
  backgroundColor: '#FFFFFF',
  borderWidth: 4,
  borderColor: '#FF69B4',
}
```

**Example:**
- Width 140 → borderRadius 70 ✅ BULAT
- Width 120 → borderRadius 60 ✅ BULAT
- Width 100 → borderRadius 50 ✅ BULAT

## 🚀 **CARA MELIHAT CAROUSEL:**

1. **Start Server:**
   ```powershell
   cd C:\BabyGrow\mobile-app
   npx expo start --port 8082
   ```

2. **Scan QR** dengan Expo Go

3. **First Launch:**
   - Splash screen (2 detik)
   - **5 Slide Onboarding** muncul
   - Swipe untuk lihat semua slide
   - Tap "Mulai Sekarang" di slide terakhir

4. **Jika Tidak Muncul:**
   - Uninstall app dari HP
   - Scan QR lagi (reinstall)
   - Onboarding akan muncul
